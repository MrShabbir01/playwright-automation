# Playwright Automation — Ostad Project

A personal automation project using Playwright to practice and demonstrate browser-based test automation.

## Project Overview

This repository contains Playwright automation tests developed for the Ostad project. It supports two execution modes: sequential and parallel.

## Running Tests

### Sequential Execution

Run tests sequentially:

```bash
npm run test:sequential
```

### Parallel Execution

Run tests in parallel:

```bash
npm run test:parallel
```
